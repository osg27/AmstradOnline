## COMPLETED INDEX CLEANUP

### Tracked Python bytecode — completed

- Candidates: tracked `backend/app/**/__pycache__/*.pyc` files.
- Evidence: generated by CPython, ignored by `__pycache__/` and `*.py[cod]`, source `.py` files exist, and several change merely by importing/running code.
- Action: 11 tracked files were removed from the Git index with `git rm --cached`; local files remain ignored.

### Tracked `frontend/dist/` — completed

- Candidate: all tracked files under `frontend/dist/`.
- Evidence: `frontend/package.json` generates this tree with `vite build`; `.gitignore` excludes `frontend/dist/`; the audited build recreated/changed it successfully from `frontend/src` and `frontend/public`.
- Evidence added: `scripts/deploy-vps.sh` always runs `npm run build` after pulling, and Vite copies the versioned `frontend/public/` runtime source into `dist`.
- Action: 224 tracked files were removed from the Git index with `git rm -r --cached`; the local directory remains intact and ignored.

## PROBABLY SAFE

- Candidates: `keropi/config`, `keropi/sram.dat` (and inspect `.keep`).
